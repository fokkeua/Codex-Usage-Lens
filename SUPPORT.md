# Support

## Usage questions

Before opening an issue:

1. Read [README.md](README.md) and [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md).
2. Confirm that macOS and Swift meet the documented requirements.
3. Reproduce the problem with the latest release.
4. Remove prompts, credentials, account identifiers, session contents, local
   paths, and unrelated logs from any diagnostic material.

Use the GitHub bug-report template for reproducible defects and the
feature-request template for proposed improvements.

This community project provides support on a best-effort basis. It cannot
answer OpenAI account, subscription, billing, or service-support questions.

## Security issues

Do not use public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md).
